What Tidy does

From a pile of downloads to folders you can find things in.

Every semester your Downloads fills up with slides, past papers, lab sheets and screenshots named final_v2 (3).pdf. Tidy reads what each file is about and files it under the course it belongs to — so the night before an exam, everything for that course is in one place.

Features

Careful by default. Fast when you want it.

  • 01

    Waits for downloads to finish

    Ignores .crdownload, .part and other in-progress files, and checks that a file has stopped growing before touching it.

  • 02

    Sorts by your subjects

    Matches the filename against each course’s name and topics. If that’s not enough, it reads the text inside PDF, Word and text files.

  • 03

    Then by file type

    Inside each subject, files are grouped into Documents, Images, Code, Slides, Spreadsheets, Archives and more.

  • 04

    You confirm every move

    Each batch shows the exact folder tree it will create. Untick anything you’d rather leave where it is.

  • 05

    Undo anything

    Put a single file back, or revert the whole last batch with one click. Tidy keeps a history of every move.

  • 06

    Import your syllabus

    Paste a course list or syllabus and Tidy proposes subjects and keywords for you to review — no typing rules by hand.

  • 07

    Cleans up the backlog

    Sort the files already sitting in Downloads, or re-check your sorted folders after you add new subjects.

  • 08

    Stays out of the way

    Lives in the menu bar or system tray and keeps watching after you close the window. Starts with your computer if you want.

How it works

Set up in about a minute.

  1. 01

    Pick two folders

    The folder to watch — usually Downloads, pre-selected for you — and an empty folder where sorted files should live.

  2. 02

    Tell it your courses

    Type them one per line, or paste your syllabus. Adding topics like Calculus: limits, integrals makes matching sharper.

  3. 03

    Download as usual

    When a download finishes, Tidy proposes where it should go and waits for your OK. Busy? Leave it for later.

  4. 04

    Confirm, or undo

    Files are moved — never copied over or deleted. Change your mind and they go right back.

Under the hood

How Tidy picks a subject.

Tidy only ever chooses between the subjects you give it. It would rather say “not sure” than guess — uncertain files go to General, where you can move them during review.

  1. 1 · Read the name

    integration_by_parts_notes.pdf → integration parts notes

    Splits the filename into words — including camelCase and run-together names — and drops filler like “notes” or “final”.

  2. 2 · Look inside if needed

    scan_0031.pdf → “…the derivative of a limit…”

    When the name says nothing useful, Tidy reads the text of PDF, DOCX and TXT files — locally, on your machine.

  3. 3 · Require a clear winner

    Calculus Physics

    Each subject is scored on keywords, phrases, acronyms and near-spellings, plus a small on-device language model for meaning. A subject must clearly beat the runner-up.

Privacy & safety

Your files stay yours.

  • Runs on your computer

    No account, no cloud, no API key. Files and their contents are never uploaded anywhere.

  • Never overwrites

    If a file with the same name already exists, Tidy saves yours as name (2).pdf.

  • Never deletes

    Tidy only moves files. It has no delete action at all.

  • Always reversible

    Every move is logged, so a single file or a whole batch can go back where it came from.

FAQ

Questions, answered.

Does Tidy upload my files or need the internet?

No files are ever uploaded. On first launch Tidy downloads a small (~23 MB) language model once, which helps it understand topics. If that download isn’t possible, Tidy still works using keyword matching.

Will it move files without asking?

No. Every new download is shown to you first with the folder it will go to. Nothing moves until you press confirm — and you can untick any file.

What if it puts something in the wrong subject?

Press Undo next to the file, or Revert last batch. Then add a keyword to the right subject in Rules — and use Fix mis-sorted files to re-check everything already sorted.

What happens to files that don’t match any subject?

They go to a General folder, still grouped by type. Tidy never forces a guess when it isn’t confident.

Can I use it for things other than courses?

Yes. A “subject” is just a folder name plus keywords — projects, clients, hobbies or anything else work the same way.

Does it touch files that are already in Downloads?

Only if you ask. Tidy up Downloads now previews the existing files so you can choose what to move. Otherwise Tidy only looks at new files.

macOS says the app can’t be opened. What do I do?

Open System Settings → Privacy & Security, scroll down and choose Open Anyway next to Tidy. You only need to do this once.

Is it free?

Yes — free for personal use.
